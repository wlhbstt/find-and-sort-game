# Art sources

The 111 object images in `public/assets/fluent-emoji/` come from [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji), pinned to commit `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`. Each PNG is the corresponding `assets/<emoji name>/3D/<emoji_name>_3d.png` file in that repository.

These images are distributed under the MIT license. The original copyright and license notice is included at `public/assets/fluent-emoji/LICENSE`. The ten item SVGs in `public/assets/items/`, seven scene SVGs, and interface styling are original work for this prototype.

The two cropped photos in `public/assets/people/` came from the reference screenshots supplied by the user in this conversation. They are composited into the Level 6 and 7 backgrounds by `npm run art:gym`. These private photos and composites are excluded from the public Git repository. Their rights for public distribution have not been established; obtain permission from the photo owners before publishing the game.
