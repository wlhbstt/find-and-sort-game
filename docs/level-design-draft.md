# 找物分类游戏：七关内容草案

状态：七关均已有固定场景、物品坐标、素材和遮挡关系，并通过五格通关路径检查。

## 统一规则

- 每关有一张可上下左右拖动的大场景；顶部三个类别框和临时物品框固定在屏幕上。
- 页面同时显示三个类别。任一类别达标时，仅该框换成队列中的下一类别。当前显示类别的物品点击后直接计数；未显示类别的物品进入临时框，在该类别显示时自动计数并腾格。
- 被任何剩余物品压住的物品不可点击，哪怕部分露出；每关的物品位置与叠放关系固定。
- 物品有固定但不同的轻微旋转、尺寸和位置偏移；覆盖关系按旋转后的不透明像素计算。
- 每个类别的实际物品数恰好等于目标数。所有可点击物品都属于本关目标类别。
- 每关初始五个临时格。输入“万理华最帅”每次解锁一格，最多十格；新关卡恢复五格。当前开放格子满时弹出失败提示，可解锁一格、撤回或重试。
- 输入“我老公是万理华”每次撤回最近一次点击，并恢复物品、覆盖关系、计数和类别框。退出游戏后保存本关状态；主动重试才清空。
- 每个固定布局应验证从五格起始状态存在通关路径。额外格数和撤回是容错，不作为可解性的必要条件。

## 制作检查

- 每件物品需要类别、位置、轮廓点击区和覆盖关系。拖动场景不应触发拾取。
- 每个类别的物品数必须等于目标数；所有类别目标数之和必须等于关卡总数。
- 覆盖关系不得成环；从五格起始状态模拟完整通关，检查不会因为某类全部被压住而无解。
- 保存与撤回必须包含类别框替换及暂存物品自动结算产生的状态变化。
- 背景音乐保留默认曲目，支持从 iPhone“文件”导入本地音频，并提供音量与静音设置。
